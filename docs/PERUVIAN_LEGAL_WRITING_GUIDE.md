# Guía de redacción jurídica de NovaCase

Esta guía define criterios editoriales del producto. No es una norma procesal ni una plantilla oficial, y no reproduce textos de documentos de referencia.

## Familias de documentos

- **Informe jurídico:** identifica objeto y alcance, antecedentes, cuestiones, fuentes verificadas, análisis, prueba, argumentos, riesgos, actuaciones y conclusiones. Omite los apartados que no tengan contenido suficiente.
- **Decisión jurisdiccional:** puede organizarse alrededor de asunto, antecedentes, fundamentos por cuestión y decisión. NovaCase puede aprender ese orden lógico, pero no debe presentarse como tribunal ni emitir una resolución oficial.
- **Informe institucional:** suele identificar destinatario, emisor, asunto, referencia y fecha, seguido de antecedentes, marco de actuación, análisis y conclusiones. Esos campos solo aparecen cuando se conocen.
- **Escrito procesal:** puede requerir sumilla, expediente, petitorio, fundamentos, medios probatorios, anexos y petición final. NovaCase no adopta esta forma salvo que el usuario solicite ese tipo de documento.

## Estilo

La redacción debe ser formal, sobria y precisa. Los párrafos desarrollan la relación entre regla, hechos relevantes, evidencia, aplicación y conclusión. Los subtítulos organizan cuestiones concretas; las listas se reservan para enumerar problemas, pruebas, actuaciones o conclusiones cuando faciliten su revisión.

El informe distingue el relato o alegación de un hecho respaldado. La presencia de una afirmación en un documento acredita que allí consta, pero no demuestra por sí sola que sea verdadera. La cronología usa fechas explícitas y no completa fechas ausentes.

## Fuentes y conclusiones

Las referencias se integran donde respaldan una afirmación jurídica o documental. Solo se citan fuentes recuperadas o fragmentos del expediente vinculados al mismo caso. Una hipótesis normativa preliminar no se presenta como autoridad verificada. No se completan artículos, fundamentos, fechas, URLs ni datos de jurisprudencia por memoria.

Las conclusiones responden a las cuestiones analizadas y derivan del contenido expuesto. No incorporan hechos o autoridades nuevos. El resultado se identifica como informe de análisis preparado para revisión profesional, sin suplantar a una autoridad pública.

## Estructura adaptativa

El perfil inicial `analysis_report` es un informe jurídico de análisis del caso. La estructura se adapta a la materia, a las fuentes y a la prueba disponible. No crea secciones vacías para satisfacer una plantilla ni alarga el texto con listas genéricas. Perfiles futuros podrán usar otras familias documentales sin cambiar el razonamiento ya generado.
